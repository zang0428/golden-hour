# Golden Hour

自己用的脚本和小工具，凑在一起方便找，也方便同步到别的电脑。

## 目录

| 目录 | 放什么 |
| --- | --- |
| `timetable/` | 把课表配置转成手机日历（.ics）的脚本，含放假调休处理 |
| `scripts/` | 零散的自用小脚本 |
| `notes/` | 速查表、笔记 |

每个子目录有自己的 README，写清楚怎么用。

## 约定

- 任何密钥、令牌、账号信息都不进仓库，本地配置用 `.local.json` 命名，`.gitignore` 已经排除。
- 只放自己有权利公开的代码，别人项目的代码不往这里搬。
