# 课表转手机日历

把课表写进一个 JSON 配置，脚本生成 `.ics` 文件，导进手机日历后每节课按周自动重复，还能提前提醒。放假调休不用手动删事件，在配置里写一段假期区间就行。

## 用法

```bash
python timetable_to_ics.py courses.json -o 我的课表.ics
```

配置可以照抄 [courses.example.json](courses.example.json) 再改。个人的真实课表建议另存为 `courses.json`，这个文件名已经被 `.gitignore` 排除，不会误传到仓库里。

## 配置怎么写

- `week1_monday`：第 1 周的周一日期。所有周次都以它为基准推算。
- `periods`：每一节课的开始和结束时间，按你学校作息填。选课时的「第 3-4 节」就是 `"periods": [3, 4]`。
- `courses`：
  - `weekday`：1 到 7，1 是周一，7 是周日。
  - `periods`：连堂课写首尾两节，中间自动连起来，比如 `[11, 13]` 表示第 11 到 13 节。
  - `weeks`：`from` 和 `to` 是起止周；单周课写 `"step": 2`，从奇数周开始就是单周。
- `holidays`：放假区间，只要落在这个日期范围内的课都会被标成不上，不用一条条列。
- `makeups`：调休补课，直接写具体的开始和结束时间。
- `alarm_minutes`：提前多少分钟提醒，写 `0` 就是不提醒。

## 导入手机

生成的文件传到手机后点开：iPhone 选「添加到日历」，安卓选系统日历或 Google 日历。导入的是一份独立日历，不想要了整份删掉即可。

## 依赖

只用 Python 标准库，不需要装任何第三方包。
